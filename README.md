# Gravity Duel

同一台電腦、雙人鍵盤對打的 2D 機器人格鬥遊戲。目前進度：**M1 核心物理與雙人輸入**。

## 執行

直接用瀏覽器開啟 `index.html` 即可，不需要伺服器或安裝。點一下遊戲畫面讓鍵盤輸入生效。

## 操作

| 動作 | P1 | P2 | P2 筆電替代 |
|---|---|---|---|
| 移動 | W A S D | 方向鍵 | 方向鍵 |
| 跳躍 / 推進 | G | Num 2 | L |
| 衝刺 | 左 Shift | Num 0 | / |
| 防禦 | H | Num 3 | ; |
| 攻擊（M2） | F | Num 1 | K |
| 切換武器（M2） | R | Num 5 | O |

系統鍵：`Esc` 暫停，暫停中 `Enter` 重置、`1` 地球、`2` 太空，`` ` `` 開關除錯資訊。

## 專案結構

- `src/config.js`：機體、場景、手感參數、按鍵配置。調平衡只改這裡。
- `src/input.js`：鍵盤狀態與按下事件鎖存，短按不會漏掉。
- `src/physics.js`：固定 60 Hz 物理，不碰 DOM，可以在 Node 測試。
- `src/render.js`：Canvas 繪圖、粒子、HUD。
- `src/main.js`：主迴圈、暫停、失焦處理、頁面控制。
- `tests/physics.test.js`：`node tests/physics.test.js`

## 里程碑

1. **M1 核心物理**（完成）：移動、跳躍、重力、平台、衝刺、燃料與過熱、機體推擠、雙人輸入。
2. M2 武器系統：四種彈藥、重力係數、命中判定、HP 與能量。
3. M3 選擇流程：標題、機體、武裝、場景畫面。
4. M4 太空場景：移動隕石、燃料平衡。
5. M5 打磨：防具、火神砲、回合制、音效、按鍵重綁。

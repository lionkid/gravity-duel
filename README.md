# Gravity Duel

同一台電腦、雙人鍵盤對打的機甲格鬥遊戲。地球與太空的重力不同，實體彈藥的彈道也不同，要依場景選對武器。
可以單人對戰電腦、兩人在同一台電腦對打，或兩台電腦透過區域網路連線對打。三個場景：地球、月面基地、太空。

## 執行

直接用瀏覽器開啟 `index.html` 即可，不需要伺服器或安裝。點一下遊戲畫面讓鍵盤輸入生效。

## 區域網路對戰

需要一台電腦安裝 [Node.js](https://nodejs.org/)（16 版以上），不需要安裝任何套件。

1. 在那台電腦的專案資料夾執行：

   ```
   node server/lan-server.js
   ```

   畫面會列出網址，例如 `http://192.168.1.20:8080`。要換連接埠就加在後面：`node server/lan-server.js 9000`。
2. 兩台電腦都用瀏覽器打開那個網址（執行伺服器的電腦也可以用 `http://localhost:8080`），選「區域網路對戰」。
3. 先連上的是主機（PLAYER 1），負責計算整場戰鬥並選擇場景；後連上的是 PLAYER 2。

兩台電腦要在同一個網路。每台電腦的鍵盤左右兩側都能操作自己的機體。暫停與 KO 選單任一方按下，兩邊會一起切換。
如果另一台連不上，請確認防火牆允許 Node.js 使用該連接埠。直接雙擊 `index.html` 或在 claude.ai 預覽中無法連線，因為那裡沒有伺服器。

## 流程

- **單人模式**：標題 → 電腦強度 → 選擇機體 → 武裝配置 → 選擇場景 → 對戰。
- **雙人模式**：標題 → 選擇機體 → 武裝配置 → 選擇場景 → 對戰。
- **區域網路對戰**：標題 → 連線大廳 → 選擇機體 → 武裝配置 → 主機選擇場景 → 對戰。
- KO 後可以再戰、換武裝或換機體。
兩位玩家在選單中同時操作，各自按攻擊鍵準備，雙方都準備好就自動進入下一步。
視角可在標題或暫停選單切換 2.5D（預設）與 2D。上次的選擇會記在瀏覽器裡。

## 電腦對手

電腦在你選好場景時決定自己的機體與武器，選場景畫面會顯示它的配置與理由。選機體和武裝時，電腦那一側只會顯示剪影。

| 強度 | 配裝 | 操作 |
|---|---|---|
| 簡單 | 隨機挑選 | 反應慢、常打歪、幾乎不防禦 |
| 普通 | 挑選在該場景有利的武器 | 看距離切換遠程與近戰，偶爾防禦與攔截 |
| 困難 | 依場景挑選，並針對你的機體與武器 | 預判彈道、攔截火箭、近身時防禦 |

電腦和玩家用同一套規則與數值，沒有額外加成。單人模式中，鍵盤左右兩側的按鍵都能操作你的機體。

## 操作

每位玩家的動作鍵都集中在移動鍵旁邊的 2×3 小區塊，兩人形狀相同：

```
        P1            P2 數字鍵區      P2 筆電
切換 衝刺   R  T         Num4 Num5        O  P
攻擊 火神   F  G         Num1 Num2        L  ;
防禦        V            Num0             .
```

| 動作 | P1 | P2 | P2 筆電替代 |
|---|---|---|---|
| 移動 | A D | ← → | ← → |
| 跳躍・噴射（空中按住） | W | ↑ | ↑ |
| 按住往下穿越平台 | S | ↓ | ↓ |
| 攻擊・選單確認 | F | Num 1 | L |
| 火神砲・選單返回 | G | Num 2 | ; |
| 切換遠程 ⇄ 近戰 | R | Num 4 | O |
| 衝刺 | T | Num 5 | P |
| 防禦（太空中兼逆噴射煞車） | V | Num 0 | . |

- 按住上或下再攻擊可以抬高或壓低射角。地球上抬高射角會順便跳起來。
- 太空中四個方向鍵都是噴射方向，放開後保持慣性。
- 切換武器後 3 秒內不能再切換，剛換上的武器有 0.3 秒出手準備。HUD 右下角會倒數。
- 輸入緩衝：攻擊、衝刺、切換在冷卻結束前 0.15 秒內按下，會在可以動作的瞬間自動送出。
- 系統鍵：`Esc` 暫停，`Enter` 確認，`M` 音效開關，`` ` `` 除錯資訊。
- 不用鍵盤也能玩：遊戲畫面下方有兩組按鈕手把和暫停、確認鍵，滑鼠與觸控都能用。觸控螢幕支援多指同時按，兩人可以在平板上各用一組。

## 場景

| 場景 | 重力 | 特性 |
|---|---|---|
| 地球 | 1.0 G | 有空氣：光束越遠越弱，爆風完整。站在地上開火沒有後座力。 |
| 月面基地 | 0.17 G | 真空：爆風縮小、能量回復變慢。跳得又高又久，空中開火會被後座力推開。 |
| 太空 | 0 G | 真空、沒有地面。所有彈藥直線飛行，每一發都有後座力。 |

## 武器

每架機體帶一把遠程、一把近戰，加上內建的頭部火神砲。彈藥下墜加速度 = 場景重力 × 0.5 × 重力係數。
每把武器在每個場景都有寫明的弱點，武器卡與選場景畫面都會顯示。

| 武器 | 傷害 | 重力係數 | 主要弱點 |
|---|---|---|---|
| BEAM RIFLE 光束步槍 | 70 | 0.0 | 每發 30 能量；地球上距離越遠傷害越低；真空能量回復慢 |
| HYPER BAZOOKA 火箭砲 | 140 直擊 / 55 爆風 | 1.0 | 地球明顯下墜；真空爆風縮小；彈速慢可被擊落；後座力大 |
| MACHINE GUN 機槍 | 10 | 0.6 | 小口徑被裝甲克制；連射後座力；45 發 |
| CRACKER 榴彈 | 80 直擊 / 90 爆風 | 1.5 | 月面拋過頭、太空無法拋投；會炸到自己 |
| BEAM SABER 光束軍刀 | 190 | — | 距離最短；太空被拉開距離很吃虧 |
| HEAT AXE 熱能戰斧 | 280 | — | 前搖長；太空漂移中容易揮空（揮動中不會被打斷，防禦也吃一半） |
| BEAM LANCE 光束長槍 | 195 | — | 只刺得到中段，地球上跳起來的對手刺不到 |
| VULCAN 火神砲（內建） | 6 | 0.5 | 小口徑，獨立按鍵，48 發 |

### 平衡驗證

`tests/balance.test.js` 讓兩台困難電腦用同一架機體、只差一把武器，在三個場景各打循環賽（每組 80 場、固定種子，結果可重現）。
每把武器在每個場景的勝率都必須落在 30% 到 70% 之間，而且至少有一個場景低於 60%。目前結果：

| 武器 | 地球 | 月面 | 太空 |
|---|---|---|---|
| 光束步槍 | 51% | 60% | 50% |
| 火箭砲 | 48% | 44% | 43% |
| 機槍 | 43% | 45% | 52% |
| 榴彈 | 59% | 51% | 56% |
| 光束軍刀 | 59% | 53% | 44% |
| 熱能戰斧 | 51% | 49% | 50% |
| 光束長槍 | 41% | 48% | 56% |

## 音效

所有音效都由 Web Audio 即時合成，不需要音效檔，並依機體位置左右聲道定位。瀏覽器規定要先按一個鍵或點一下才會出聲。標題或暫停選單可以開關，也可以按 `M`。

## 專案結構

- `src/config.js`：機體、武器、場景、手感參數、按鍵配置。調平衡只改這裡。
- `src/input.js`：鍵盤狀態與按下事件鎖存，短按不會漏掉。
- `src/physics.js`：固定 60 Hz 物理，不碰 DOM，可以在 Node 測試。
- `src/combat.js`：武器、彈道、爆炸、命中、擊退、切換冷卻、KO。同樣不碰 DOM。
- `src/render.js`：2D Canvas 繪圖、粒子、HUD。
- `src/render3d.js`：2.5D renderer，繼承 2D 版，方塊機體與透視鏡頭，無外部套件。
- `src/ai.js`：電腦對手的配裝邏輯與每一步的操作，不碰 DOM。
- `src/audio.js`：合成音效。
- `src/net.js`：區域網路連線，以及主機快照、來賓輸入的同步函式。
- `server/lan-server.js`：區域網路伺服器，零依賴，提供網頁並轉送雙方訊息。
- `src/screens.js`：標題、電腦強度、選機體、武裝、場景、暫停、KO、說明等選單畫面。
- `src/touch.js`：畫面上的按鈕手把，送出的指令與鍵盤相同。
- `src/main.js`：主迴圈、畫面流程、視角切換、記住選擇。
- `tests/`：`for t in physics combat ai net balance lan-server; do node tests/$t.test.js; done`

## 里程碑

1. **M1 核心物理**（完成）：移動、跳躍、重力、平台、衝刺、燃料與過熱、機體推擠、雙人輸入。
2. **M2 武器系統**（完成）：武器、火神砲、重力係數彈道、命中與爆炸、防禦、硬直、能量與彈藥、KO。
3. **M3 選擇流程**（完成）：標題、選機體、武裝配置、選場景、暫停與 KO 選單、2.5D 視角、畫面按鈕、單人模式與三段電腦強度。
4. M4 太空場景：移動隕石、燃料平衡。
5. M5 打磨：防具、回合制與計時、音效、按鍵重綁。

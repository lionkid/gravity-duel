# Gravity Duel

同一台電腦、雙人鍵盤對打的 2D 機器人格鬥遊戲。目前進度：**M2 武器系統**。

## 執行

直接用瀏覽器開啟 `index.html` 即可，不需要伺服器或安裝。點一下遊戲畫面讓鍵盤輸入生效。

## 操作

| 動作 | P1 | P2 | P2 筆電替代 |
|---|---|---|---|
| 移動 | W A S D | 方向鍵 | 方向鍵 |
| 跳躍 / 推進 | G | Num 2 | L |
| 衝刺 | 左 Shift | Num 0 | / |
| 防禦 | H | Num 3 | ; |
| 攻擊（按住上/下改變射角） | F | Num 1 | K |
| 切換主武器 ⇄ 火神砲 | R | Num 5 | O |

系統鍵：`Esc` 暫停，暫停或 KO 後 `Enter` 重來，暫停中 `1` 地球、`2` 太空，`` ` `` 開關除錯資訊。

## 武器與重力

每種彈藥有一個重力係數，實際下墜加速度 = 場景重力 × 0.5 × 係數。

| 武器 | 傷害 | 重力係數 | 彈藥 | 特性 |
|---|---|---|---|---|
| BEAM RIFLE 光束步槍 | 90 | 0.0 | 無限，每發 30 能量 | 兩地穩定，能量不足無法發射 |
| HYPER BAZOOKA 火箭砲 | 180 | 1.0 | 4 發 | 爆風 70 px，可被子彈擊落，太空最強遠距 |
| MACHINE GUN 機槍 | 22 | 0.6 | 60 發 | 按住連射，±3° 散布 |
| CRACKER 榴彈 | 120 | 1.5 | 6 發 | 地球拋物線落地爆炸，太空 3 秒空爆，會傷到自己 |
| BEAM SABER 光束軍刀 | 150 | — | 無限 | 近戰 70 px，出刀 4 幀無敵，衝刺中距離 +30 |
| VULCAN 火神砲（內建） | 8 | 0.5 | 48 發 | 切換鍵啟用，適合擊落火箭 |

傷害 × (1 − 裝甲 × 0.06)。正面防禦只吃 25% 傷害、不硬直。太空的擊退是加速度而非設定速度，會漂得更遠。

## 2.5D 原型

`prototype-2.5d.html` 用同一套物理與武器，換成透視鏡頭與立體方塊機體（`src/render3d.js`，無外部套件）。
戰鬥仍在同一個平面上，屬於視覺 2.5D。尚未成為正式 renderer，`index.html` 仍是 2D 版。

## 專案結構

- `src/config.js`：機體、場景、手感參數、按鍵配置。調平衡只改這裡。
- `src/input.js`：鍵盤狀態與按下事件鎖存，短按不會漏掉。
- `src/physics.js`：固定 60 Hz 物理，不碰 DOM，可以在 Node 測試。
- `src/combat.js`：武器、彈道、爆炸、命中、擊退、KO。同樣不碰 DOM。
- `src/render.js`：Canvas 繪圖、粒子、HUD。
- `src/render3d.js`：2.5D renderer，繼承 2D 版，方塊機體與透視鏡頭（原型）。
- `src/main.js`：主迴圈、暫停、失焦處理、頁面控制。
- `tests/physics.test.js`、`tests/combat.test.js`：`node tests/physics.test.js && node tests/combat.test.js`

# Gravity Duel

同一台電腦、雙人鍵盤對打的機甲格鬥遊戲。地球與太空的重力不同，實體彈藥的彈道也不同，要依場景選對武器。
目前進度：**M3 選擇流程**。

## 執行

直接用瀏覽器開啟 `index.html` 即可，不需要伺服器或安裝。點一下遊戲畫面讓鍵盤輸入生效。

## 流程

標題 → 選擇機體 → 武裝配置 → 選擇場景 → 對戰 → KO 後再戰、換武裝或換機體。
兩位玩家在選單中同時操作，各自按攻擊鍵準備，雙方都準備好就自動進入下一步。
視角可在標題或暫停選單切換 2.5D（預設）與 2D。上次的選擇會記在瀏覽器裡。

## 操作

| 動作 | P1 | P2 | P2 筆電替代 |
|---|---|---|---|
| 移動 | A D | ← → | ← → |
| 跳躍・噴射（空中按住） | W | ↑ | ↑ |
| 按住往下穿越平台 | S | ↓ | ↓ |
| 攻擊・選單確認 | F | Num 1 | K |
| 火神砲・選單返回 | G | Num 2 | L |
| 切換遠程 ⇄ 近戰 | R | Num 5 | O |
| 防禦（太空中兼逆噴射煞車） | H | Num 3 | ; |
| 衝刺 | 左 Shift | Num 0 | / |

- 按住上或下再攻擊可以抬高或壓低射角。地球上抬高射角會順便跳起來。
- 太空中四個方向鍵都是噴射方向，放開後保持慣性。
- 切換武器後 3 秒內不能再切換，剛換上的武器有 0.3 秒出手準備。HUD 右下角會倒數。
- 系統鍵：`Esc` 暫停，`Enter` 確認，`` ` `` 除錯資訊。

## 武器

每架機體帶一把遠程、一把近戰，加上內建的頭部火神砲。
彈藥下墜加速度 = 場景重力 × 0.5 × 重力係數。

| 武器 | 類型 | 傷害 | 重力係數 | 特性 |
|---|---|---|---|---|
| BEAM RIFLE 光束步槍 | 遠程 | 70 | 0.0 | 每發耗 30 能量 |
| HYPER BAZOOKA 火箭砲 | 遠程 | 130 直擊 / 55 爆風 | 1.0 | 爆風半徑 120，4 發，可被子彈擊落 |
| MACHINE GUN 機槍 | 遠程 | 15 | 0.6 | 按住連射，60 發 |
| CRACKER 榴彈 | 遠程 | 90 直擊 / 75 爆風 | 1.5 | 爆風半徑 150，會炸到自己，太空 3 秒空爆 |
| BEAM SABER 光束軍刀 | 近戰 | 220 | — | 出刀最快，4 幀無敵 |
| HEAT AXE 熱能戰斧 | 近戰 | 300 | — | 前搖長，對方防禦也吃一半傷害 |
| BEAM LANCE 光束長槍 | 近戰 | 170 | — | 攻擊距離 120 |
| VULCAN 火神砲（內建） | 副武器 | 6 | 0.5 | 獨立按鍵，48 發 |

傷害 × (1 − 裝甲 × 0.06)。正面防禦只吃 25% 傷害且不硬直（戰斧例外為 50%）。

## 專案結構

- `src/config.js`：機體、武器、場景、手感參數、按鍵配置。調平衡只改這裡。
- `src/input.js`：鍵盤狀態與按下事件鎖存，短按不會漏掉。
- `src/physics.js`：固定 60 Hz 物理，不碰 DOM，可以在 Node 測試。
- `src/combat.js`：武器、彈道、爆炸、命中、擊退、切換冷卻、KO。同樣不碰 DOM。
- `src/render.js`：2D Canvas 繪圖、粒子、HUD。
- `src/render3d.js`：2.5D renderer，繼承 2D 版，方塊機體與透視鏡頭，無外部套件。
- `src/screens.js`：標題、選機體、武裝、場景、暫停、KO、說明等選單畫面。
- `src/main.js`：主迴圈、畫面流程、視角切換、記住選擇。
- `tests/`：`node tests/physics.test.js && node tests/combat.test.js`

## 里程碑

1. **M1 核心物理**（完成）：移動、跳躍、重力、平台、衝刺、燃料與過熱、機體推擠、雙人輸入。
2. **M2 武器系統**（完成）：武器、火神砲、重力係數彈道、命中與爆炸、防禦、硬直、能量與彈藥、KO。
3. **M3 選擇流程**（完成）：標題、選機體、武裝配置、選場景、暫停與 KO 選單、2.5D 視角。
4. M4 太空場景：移動隕石、燃料平衡。
5. M5 打磨：防具、回合制與計時、音效、按鍵重綁。
